# Décisions

- **Preact + Dexie** : léger, démarrage rapide.
- **Navigation par hash** (`#/...`) : fonctionne sur GitHub Pages sans configuration serveur.
- **Base `/Basse-apprentissage-/`** pour Pages ; surchargeable via `BASE_PATH`.
- **Rappel quotidien** : pas de push sans serveur ; repli prévu par fichier .ics.
- **Icône SVG unique** (pas de PNG) pour la phase 1.
- **Détection YIN décimée ×4 + affinage pleine résolution** : ~4 ms/détection (contre ~17 ms), même précision (45/45 notes B0→G4 à ±2 cents sur sons de synthèse). Buffer 8192 @48 kHz : couvre le Si grave (30,87 Hz).
- **Médiane sur 5 mesures + lissage exponentiel** de l'aiguille ; seuil de clarté 0,8 ; silence sous RMS 0,003 = « signal trop faible ».
- **Calibration de latence** : médiane (attaque − clic), temps de réaction humain inclus volontairement. Valeurs séparées USB / Bluetooth.
- **Contexte audio partagé** entre accordeur, métronome et futurs backings ; le micro est libéré à la fermeture de l'accordeur.
- Accordeur du Plug Pro (BLE) repoussé à la phase 9.
- **Validation par hauteur, pas par case** : l'audio ne distingue pas les cordes. « Toutes les positions » = toutes les hauteurs distinctes de la zone ; « note sur une corde » accepte toute octave présente sur cette corde dans la zone.
- **Déblocage des zones** : moyenne des 3 dernières séances de la zone ≥ 90 % (3 séances minimum). Option « Tout débloquer » dans les réglages (le test de positionnement pourra aussi débloquer).
- **Réussite d'une séance** = notes justes / (justes + fausses) ; « Passer » compte les notes restantes comme fausses.
- **Carte de chaleur** par hauteur : maîtrisée ≥ 90 % et < 3 s ; lente > 3 s ; ratée < 70 %. Symboles ✓ ⏱ ✗ en plus des couleurs.
- **Répétition espacée** : boîtes de Leitner (0/1/2/4/8/16 jours), tirage pondéré (jamais vu 2, raté 3 + retard, non dû 0,2).
- **Backings 100 % synthétisés** (aucun fichier audio) : batterie bruit+oscillateurs, claviers, guitare, orgue. Planification pure (`plan.ts`, testée) séparée du rendu audio (`voices.ts`). Limiteur maître pour éviter toute saturation (crêtes mesurées ≤ 0,8).
- **Swing** : retard de la 2ᵉ croche jusqu'à 1/3 de croche ; blues = grille ternaire à 12 pas (shuffle exact, sans réglage).
- **Aucune basse** dans les accompagnements (test automatisé : voicings ≥ Ré2). La basse synthétisée n'existe que pour les phrases d'exemple (`playBassNote`).
- **Improvisation** : chaque exercice = un script par mesure (`makeScripts`) + une analyse pure (`analyze`) testée avec des « joueurs » simulés (parfait = 100 %, fautif = sanctionné). Tolérance rythmique = min(90 ms, 0,2 temps). La latence calibrée est soustraite aux instants des notes.
- **« Une seule corde »** (contraintes) : l'audio ne détecte pas la corde ; approximé par un ambitus ≤ 7 demi-tons.
- **Octave (étape 2)** : détectée si deux fondamentales à ≥ 12 demi-tons sont jouées dans la même mesure.
- **Conseil de prof** : règles locales (hors ligne), 3 conseils max, priorisés (notes à éviter, densité sur mineur, % dans l'accord, retard/avance, fondamentale au temps 1, cibles).
- **Limite connue** : la hauteur d'une note est confirmée ≥ 100 ms après l'attaque ; des notes plus rapides que ~100 ms peuvent être mal nommées (le rythme, lui, vient de l'attaque et reste exact).
- **Groove** : chaque note attendue est appariée à l'attaque la plus proche dans une fenêtre de ±45 % de l'espacement (≥ 30 ms). « Réussi » = écart ≤ 50 ms ; « précis » ≤ 25 ms. Montée de tempo : +5 BPM à ≥ 90 %, mémorisée par exercice.
- **Dérive sans clic** : pente des écarts moyens par mesure sur les mesures muettes (≥ 3), convertie en BPM effectif. Les séances « clic qui disparaît » sont courtes (4-16 mesures) car l'analyse compare à la grille d'origine.
- **Alternance index/majeur** : le doigt n'est pas détectable ; on mesure l'asymétrie de durée entre intervalles pairs et impairs (> 12 ms = déséquilibre).
- **Notes étouffées** : détectées comme attaques sans hauteur ; option d'auto-évaluation pour les ignorer du score.
- **Vocabulaire** : 64 phrases originales (8 par style), stockées en JSON (`src/data/phrases/*.json`), notation compacte `temps:corde+case:durée` par mesure, grille en degrés (transposable). Un test valide chaque phrase (grille, cases, cohérence harmonique ≥ 60 % de notes d'accord ; gamme blues pour le blues) dans 12 tonalités. Transposition : tessiture conservée, cases ≤ 19 au pire.
- **Partition simplifiée** = noms de notes + glyphes de durée (pas de portée réelle).
- **Capture audio → phrase** : attaques quantifiées à la double croche, durée = jusqu'à la note suivante ; à corriger via la saisie en tablature si besoin.
- **Oreille** : 4 exercices (intervalles, accords, degrés, relevé de ligne), 3 niveaux, répétition espacée ; sons 100 % synthétisés.
- **Navigation** : 5 onglets (Séance, Manche, Pratique, Outils, Réglages) ; « Pratique » regroupe Impro, Groove, Jam, Vocabulaire, Oreille.
